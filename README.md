Propósito del Proyecto

El propósito de este proyecto es enfocarse en el desarrollo de un sistema de software que permita mejorar y optimizar el proceso de Entrada y salida de equipos eléctronicos del CDATH, brindando una herramienta eficiente, segura y fácil de usar tanto para los usuarios como para los administradores.  
Con este sistema se busca solucionar problemas comunes como la pérdida de tiempo al momento de registrar un computador de forma manual, demoras al iniciar la formación y errores a la hora de registrar un equipo manualmente, garantizando un entorno más ordenado, confiable y automatizado.

Fases del Ciclo de Vida del Software
Análisis de Requisitos:
Se realiza el reconocimiento y la documentación de las necesidades tanto del usuario como del sistema.  
Incluye la recolección de información, entrevistas y levantamiento de requerimientos funcionales y no funcionales.
Diseño:
En esta fase se elaboran los diagramas del sistema, la estructura general, la base de datos y la interfaz de usuario.  
El objetivo es definir cómo se comportará el sistema antes de su construcción.
Desarrollo o Construcción:
Se lleva a cabo la programación de las funciones del sistema según los requerimientos definidos.  
Aquí se implementan los módulos, componentes y funcionalidades principales del software.
Pruebas:
Se realiza la validación del funcionamiento del sistema, la corrección de errores y los ajustes necesarios para garantizar la calidad y estabilidad del producto antes de su entrega.
Implementación:
Consiste en la puesta en marcha del sistema en un entorno real para que los usuarios finales puedan utilizarlo.
Mantenimiento:
Fase destinada a las mejoras continuas, soporte técnico, optimización del rendimiento y actualización del sistema según las nuevas necesidades del usuario o de la organización.
