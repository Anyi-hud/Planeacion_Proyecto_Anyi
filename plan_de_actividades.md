Qué dificultades encontraste al usar GitHub para planificar tu proyecto?
Durante el proceso inicial, una de las principales dificultades fue comprender el funcionamiento de las ramas, los commits y la forma en que se sincronizan los cambios entre el repositorio local y el remoto. También resultó un reto recordar la secuencia adecuada para crear y fusionar las ramas sin cometer errores. Sin embargo, con la práctica y la exploración de la plataforma, fue posible comprender mejor el flujo de trabajo y aprovechar las herramientas que ofrece GitHub.

¿Qué beneficios te aportó GitHub para organizar las tareas y visualizar el avance?
GitHub facilita la organización del proyecto gracias a su control de versiones, que permite registrar cada cambio realizado y acceder al historial de modificaciones en cualquier momento. Además, las ramas y los mensajes de commit permiten mantener un seguimiento ordenado de cada avance. Esto favorece una mejor planeación, trazabilidad y control de las actividades desarrolladas dentro del proyecto.

¿Cómo podrías integrar el control de versiones en un entorno laboral real?
En un entorno profesional, el control de versiones es una herramienta fundamental para trabajar de forma colaborativa y mantener la integridad del código fuente. GitHub permite que varios desarrolladores trabajen simultáneamente en diferentes funcionalidades mediante ramas independientes. De esta manera, se pueden integrar los cambios gradualmente, realizar revisiones de código a través de *Pull Requests* y garantizar un producto final más estable y de mayor calidad.

¿Qué aspectos del trabajo colaborativo aprendiste que podrías aplicar en el desarrollo de software dentro de un equipo profesional?
Aprendí la importancia de la comunicación, la coordinación y la responsabilidad individual dentro del trabajo en equipo. GitHub promueve buenas prácticas como la documentación constante, el registro detallado de cambios y la revisión mutua del código. Estas prácticas son esenciales para lograr un desarrollo de software eficiente, ordenado y con resultados de calidad en un entorno profesional.
